## What works / shipped this week (since 2026-09-20)

- **Shell model + reconcile**: Generate mints `rounds × (floor(n/2) + bye)` empty shells; Pair next seats one round onto them, keeping scheduled times and courts. Reconcile runs early (every unseated round) before Start and only when needed (the round being paired) after Start (#826). A later round that cannot be reshaped is skipped, not refused (5488abaf9). Organiser is told what moved (c6401a356).
- **Withdrawal**: a mid-event withdrawal no longer bricks Pair next (7cbbb8b44). Swiss never expunges: any paired board walks over to the opponent (#868, e69f89546). Withdraw copy updated to match.
- **Walkovers**: a two-sided walkover counts as played, so no rematch and no phantom bye (14c5095f2). A walkover winner is not eligible for a later bye, per FIDE C.04.1(d) (318f523ff).
- **Pre-Start delete**: no longer strands the half-emptied round; takes the division lock (deb84282c, 7544f5504). Unpair now targets a partly seated round.
- **Round 1**: pairs top-vs-bottom by default. The organiser can pick the mode for round 1 only, via a split button; later rounds get a 422 and a read-only menu (#844). Audit fields `round/pairing/override/seated_fixture_ids` added.
- **Desk legend**: states the Swiss shape ("N matches + 1 bye per round"), plus finished and empty states (7d946c7c4, e3788a996).
- **Qualification view**: knows Swiss round budget (V414 `swiss_rounds`), and a departed row's unplayed fixtures count (4b66844ea).
- **Scorer sheets**: exclude a seated bye (empty seat + `bracket.slot.bye` label), b61f93f55.
- **Engine**: backtracking, rematch-free pairing within score groups. Float tracking. FIDE colour hard rules when `chess` is on. Buchholz, Buchholz Cut-1, Sonneborn-Berger, direct encounter and wins, with a FIDE virtual opponent for byes. Chess (boardgame) default cascade: points, BH-C1, BH, SB, direct, wins, lots.

## Probe numbers (engine only, fold and rank_adjacent identical)

- Dead-end rate by field and rounds (1000 random events each): n=6 × 5 → 15.5%. n=4 × 3, 5 × 5, 7 × 5, 8 × 5, 10 × 5, 12 × 5, 6 × 3, 8 × 3 → 0%.
- Sweep n=3..9, rounds 2..n−1 (+1 for odd), 300 seeds: 361 dead-ends in 40,636 rounds. Every even-field dead-end was a true impossibility (no rematch-free matching left), meaning a greedy earlier round, not a search bug. 2 odd-field ones were fixable by a different bye.
- Buchholz: A = bye R1, beats B (who then beats C), beats C → engine BH(A) = 7 half-points (3.5). FIDE C.07 = 5 half-points (2.5).
