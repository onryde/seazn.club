Screen 1 of 4 — Stage rules: where does the organiser set them?

Division page → Fixtures tab → each stage card. Example: football, "Knockout" stage, not started. Today this row exists only for tennis/badminton/table tennis/volleyball and shows match format only. W2c adds every sport, deciders, abandon, chess tie-break rounds, and points.

A

Inline, grouped — extend today's "Format" row

The stage card keeps one summary line. "Edit rules" expands in place into grouped sections: Match format · Deciders · If abandoned · Points. Each field says whether it's the division's value or set for this stage. "Use division rules" resets. Same pattern organisers already know for sets sports.

B

Summary chips + side drawer (full-screen sheet on phone)

The stage card shows chips ("Bo1 · 2×45' · ET 2×15 · Pens · Replay if abandoned"). "Stage rules" opens a drawer with tabs: Format / Deciders / Points. More room per stage, but a new pattern and the fixtures list is hidden while editing.

My recommendation: A

  • Extends a screen organisers already use; no second pattern
  • One DOM, sections stack on phone (house rule: never a second phone tree)
  • Every field shows Division vs This stage — the inherit model is visible
  • Fixtures stay on screen; the stage card is where the lock message already lives

Against A

  • Long when a sport has many fields (cricket ~10) — mitigated: sections only show what the sport/kind/variant declares
  • B's chips are a nicer at-a-glance summary — A can borrow the chip summary line without the drawer
