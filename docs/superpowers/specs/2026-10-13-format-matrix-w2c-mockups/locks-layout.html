Screen 4 of 5 — Locked rules: how does the organiser find out?

Your Q3/Q4: once a stage that inherits the division's rules has started, the division settings refuse table points, tie-breaks and match format — by name. Other division fields still save. Example: Group A started, Knockout not yet. Same question applies to a started stage (screen 1) and a started match (screen 2).

A

Say it before they try — locked sections shown read-only with the reason

The locked sections show their values greyed with one line: "🔒 Group A has started — match format is locked. Change individual unstarted matches instead." with a link to the fixtures. Everything else stays editable. The server still refuses if anyone gets past (API, stale tab).

B

Edit freely, explain on Save

All fields look editable. On Save, the allowed fields save, and a message lists what was refused and why. Simpler to build; the organiser learns about the lock only after making the change.
