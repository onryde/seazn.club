Lives inside screen 1's form (your A), table stages only. What it can set today: win / draw / loss, walkover points and an optional walkover score (your Q9: walkover only), and bonus points (losing by ≤ N, winning by ≥ N, scoring ≥ x% of the winner, draw, no result). Per-sport point systems (chess ½, ice hockey OT/SO, cricket tie/NR) are W2d — a rule this screen can't express is refused with a reason (your Q1).

A

Sentences — every rule reads as a line, live preview on top

"A win earns [3]. A draw [1]. A loss [0]." Walkover and bonuses are sentence rows: "Losing by [7] or fewer: +[1]". "+ Add bonus" picks from the bonuses this sport supports. A one-line preview summarises the whole rule. Advanced parts (walkover score, bonuses) sit behind "More".

B

Compact table — results × points, bonuses as a list below

A small table: Win / Draw / Loss / Walkover win / Walkover loss, each with a number. Bonuses as a list of condition + points rows. Denser and faster for experienced organisers; less self-explaining.
