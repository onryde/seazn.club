Screen 2 of 4 — Changing ONE match's format before it starts

Example: badminton group stage plays best of 3 to 21. The organiser is running late and makes QF3 "best of 1 to 21". Only match-format fields (your Q5 group 1) can be changed per match. Once the match starts it's locked, named. Both options also mark the changed match in the fixtures list with a small "Format changed" tag.

A

On the match's own console page — a "Match rules" block

The fixture console (where the organiser already starts, assigns and settles a match) gets a block: "Best of 3 to 21 · uses stage rules · Change for this match". Expands to group-1 fields only, each labelled Stage vs This match. "Use stage rules" resets. After start: "Started — format locked".

B

From the fixtures list row — "⋯ → Change format" dialog

Each unstarted row in the division's fixtures tab gets a menu item opening a small dialog with the group-1 fields. Fast when running late; it's the same list the future bulk "apply to all unstarted" action (competition desk) will live next to.

My recommendation: A

  • The console is already "everything about this one match"; the lock message sits where Start is
  • No new dialog pattern; same Division/Stage/This-match labelling as screen 1
  • The list still shows the "Format changed" tag, so nothing is hidden
  • The future bulk action (competition desk) covers the running-late list case properly

Against A

  • One more click to reach a match than B's row menu
  • B is quicker for changing 2–3 matches in a row today, before bulk exists
