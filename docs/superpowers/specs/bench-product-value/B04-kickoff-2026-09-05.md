## Traps this programme has already paid for

Read `B03r-session-state-2026-09-04.md` for the full list. The five that will
cost you time in B04 specifically:

1. **The bench report directory is the git SHA.** Committing mid-investigation
   moves it, and two runs at the SAME commit overwrite each other. Resolve the
   path from each run's own log, immediately after that run.
2. **`tsconfig.scripts.json` excludes `scripts/**/*.test.ts`**, so a test
   fixture missing a newly-required field never shows up in tsc — only when the
   suite runs.
3. **A mutant that breaks collection reads as survived.** Compare the TOTAL
   (`numTotalTests`), not the failure count. One mutant here reported
   `failed 0 / 629` against a real total of 714.
4. **A mutant can compile and still be a bad probe.** Check that the mutated
   condition actually differs at the moment it is evaluated — one gated on
   `errors.length === 0` to simulate "not in a finally", and the enclosing
   `catch` writes `errors` AFTER the `finally` runs, so it was always true.
5. **cwd resets between tool calls.** `cd <abs worktree> &&` in the SAME call,
   every time. It bit four times in B03r, including one shell loop that quoted
   `--entry admin` as a single argument.

## Two findings that generalise to the checker

B04's whole claim is independent verification, so both of these apply directly:

- **A validated-but-unsent field is an inert seam wearing a validation rule as
  camouflage.** `PackOrg.currency` had a stage-0 rule forcing every priced pack
  to declare it and NO transmission path at all; the column default won and
  live charges settled in the wrong currency. When adding checker config, ask
  what each rule enforces: authoring, or effect?
- **Mutate the line that does the work, not the ones near it.** Deleting the
  bench's entire `pay()` call left 714/714 green, because the funnel oracle
  read pre-seeded rows that reported the same total either way. B04's checker
  has the same shape: a fixture that pre-seeds a clean board cannot witness a
  checker that never ran. The acceptance line already asks for this
  ("bypass checker, run must go green, restore") — do it literally.
