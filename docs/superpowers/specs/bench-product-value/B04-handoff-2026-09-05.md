## Rulings a fresh session would otherwise re-derive wrongly

- **`--engine` cannot select an engine and never could.** No field, env var,
  flag or setting picks one; the only lever is `PLACEMENT_SERVICE_HOST`, which
  is server-side. It ASSERTS what actually ran instead, which is what catches
  `_RULES.md` §2's false green.
- **Layer 1 gates four of nine conflict reasons.** Rest minima, blackouts,
  session windows, day caps and round order are gated by nothing in the
  product, so the checker is their only gate — not a second opinion.
- **Certificate branch order is `SKIPPED → PACK_AUTHORING_BUG →
  PRODUCT_DEFECT → UNPLACED → FEASIBLE`.** The design had it right and an
  earlier draft of the plan reversed the middle two. `placed < total` is a
  CONSEQUENCE of `infeasible`, so ranking `UNPLACED` first reports the symptom
  instead of the cause.
- **The FETCHED board's `judgeDivision.unplacedCount` is authoritative** for
  the unplaced gate; the certificate's proposal-derived count is a secondary,
  history-only path.
- **`gapMinutes` is not part of court occupancy** (`[start, start +
  matchMinutes)`); it is reported as unmodelled rather than assumed either way.
- **Array order in a schedule config is significant** — `putScheduleSettings`
  stores config as jsonb verbatim, so a well-behaved product cannot reorder.
- **The checker imports no value from `@seazn/engine`**, and specifically not
  `usableWindows` — the solver consumes it, so sharing it would make window
  containment a tautology. `assessHealth` is shared, report-only.

## Traps this wave actually hit

- **`tsconfig.scripts.json` excludes `scripts/**/*.test.ts`, so the suite is
  structurally blind to type errors.** This branch shipped **884 green tests on
  a tree that did not compile**. Run tsc as its own gate, every time.
- **There is no root `vitest`** — `npx vitest` resolves an unpinned copy from
  the registry. Use `./packages/engine/node_modules/.bin/vitest`, as
  `ci.yml:166-180` documents.
- **Judge every run on `numTotalTests`, not the failure count.** A suite that
  fails to collect contributes zero tests and zero failures.
- **A whole-function mutant over a closed union dies on whichever arm has
  coverage**; the rest ride along untested. Mutate per union MEMBER. This
  surfaced eight times. A grep cannot settle whether an arm is covered — one
  produced a false clear by matching an unrelated shape's `kind` field.
- **A `cp -p` backup taken before the implementation is finished silently
  reverts your own work and still reports a clean restore.** Caught only
  because tests appeared in a mutant's red list that the mutated arm could not
  reach.
- **`.superpowers/` is gitignored and per-worktree.** Reports and reviews do
  NOT travel with a branch — copy them into `bench-b04`'s workspace before
  removing any worktree.
- A peer's message is not the owner's approval; the owner's rulings are in
  §15's header and in the ledger.
