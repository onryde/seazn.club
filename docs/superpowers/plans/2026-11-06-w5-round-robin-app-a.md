### The rules stated once

- **(pair, leg) key (RB5-G7):** `rrKey(a, b, leg, pool) = \`${pool ?? ""}|rr:${lo}:${hi}:L${leg}\`` where `lo`/`hi` are `a`, `b` in code-unit order (`a < b ? a : b`) — the same pair-and-leg text as the engine's `roundRobinLineKey` (engine plan T1), so PR B's parity is a string compare. `leg` is read from the engine's `RoundRobinFixture.leg` for a fresh schedule, and for a stored line from its `ext_key` (Task 2 writes `rr-…-L{leg}` keys on every new line) or, for lines generated before this PR, from the engine schedule regenerated over the stage's stored member order (`generateRoundRobin(...).fixtures` matched on pair and round).
- **Bye (FX-G21):** the engine's `RoundRobinRound.bye` per pool and round, persisted at generate (Task 2) — never derived from "who is missing" after a roster change.
- **Catch-up (RB5-L3, L6, L16; F5):** owed = every (newcomer, member, leg) with no existing line; a member holding a **future, unstarted** bye in that leg takes the fixture in that round (`bye_slot`, consuming the bye); every other owed fixture is appended as a catch-up round at `lastRoundNo + k`, one per round, ordered by the member's **earliest existing round**, then **the members' listed (seed) order** where earliest rounds tie (designer's call 2026-11-16, F5), a member with no line last in listed order, then leg; **home side:** per leg the newcomer alternates along that leg's owed list, first away, and a pair's side flips between legs (the engine's `lateEntryFixtures` rule, E-canonical, so PR B's parity compares sides too); two late entrants owe each other. "Started" = `stageHasStarted` / `fixtureStartedSql` (`U/fixture-started-sql.ts:64,78`, pinned 2026-11-16). A newcomer who owes nothing (already seated against everyone) is a **named refusal**, never an empty success (RB5-E9; F8).
- **Who is listed (F9):** a waiting late arrival with no line is not listed in any table until seated (the stage's entrants are the seated set, `server/engine-db/competition.ts:543`, pinned 2026-11-16); only a **result** naming an unseated entrant is a defect.
