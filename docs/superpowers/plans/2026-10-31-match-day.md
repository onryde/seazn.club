# Match Day + stage clean-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Match Day, a court-by-court organiser surface for running the day. Strip the
duplicated live state from the competition and division pages. Clean up the stage card around
one reusable Match format / Points / Tie-breaks component each. Align builder and Settings
field ranges.

**Architecture:**
- **Server.** A new read model, `getMatchDay`, built over existing desk, schedule, venue,
  device-link and stream use cases. A new call/undo use case with its own hard-stop guard. It
  deliberately bypasses `moveFixture`'s planned-overlap refusal, per owner ruling B. It is
  backed by one new table, `fixture_calls`.
- **Client.** A polled client shell under a new organiser route. Pure functions (estimates,
  ranking, pagination, points/tie-break folding, stage actions, format bounds) carry the logic,
  so they're unit-testable in vitest's node environment. The UI stays thin.

**Tech Stack:** Next.js (repo version — read `node_modules/next/dist/docs/` before route work), TypeScript 7, Postgres, Tailwind v4 house tokens (`--ps-*`), vitest (node env), Playwright.

**Spec:** `docs/superpowers/specs/2026-10-31-match-day-design.md` (owner-approved 2026-10-31; §12 = phases).

## Review Focus

1. **Doubles partner busy.** A pair whose second player is on another court must be
   hard-stopped by person, not by entrant. Test it in Task A1 (`PLAYER_BUSY` via
   `peopleByEntrant`).
2. **Called, then no-show.** Undo must restore the exact previous court and time, including
   "no court". Calling again elsewhere must work. Test it in Task A1 (undo restores nulls;
   re-call).
3. **A court shared with another competition.** Its in-play match makes the court
   `in_use_elsewhere` and refuses calls. Test it in Tasks A1 and A2.
4. **A fixture leaves `scheduled` while called** (scorer starts, void, forfeit). The court must
   flip to playing or free, never stay "Called". Test it in Task A2 (status-driven state, not
   the presence of the row).
5. **Unrelated schedule-board edits** on a fixture overlapping a called match must not 409.
   Test it in Task A1 (`moveFixture` on the bumped planned match still succeeds).
