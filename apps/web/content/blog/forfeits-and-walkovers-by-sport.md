When one side does not turn up, the other side wins by walkover. But a table does not only count wins. It also counts goals, sets, games or runs, and those decide places when teams are level on points. So a walkover needs a score, and each sport's rules say what it is.

{{example:forfeit-scores}}

## Why a walkover has a score at all

Imagine a walkover counted as a win with no score. The team that got it would gain the points but nothing for goal difference, and could finish behind a team that won the same match on the pitch by one goal. The rules of each sport fix a walkover score so that a team is never worse off for the other side's absence, and the side that did not turn up pays for it.

## What changes from sport to sport

- **Football.** A walkover is {{fact:forfeit-scores.footballScore}}, the score football's rules award a forfeited match. It counts for goal difference like any other result.
- **Hockey and ice hockey.** A walkover is {{fact:forfeit-scores.hockeyScore}} in hockey and {{fact:forfeit-scores.icehockeyScore}} in ice hockey, both by their own rules.
- **Volleyball, badminton, table tennis and carrom.** The winner gets every set the match needs, each to its full score, and the other side gets nothing. On the settings a new division starts with, badminton shows {{fact:forfeit-scores.badmintonScore}}, table tennis {{fact:forfeit-scores.tabletennisScore}}, volleyball {{fact:forfeit-scores.volleyballScore}} and carrom {{fact:forfeit-scores.carromScore}}. The set and points ratios count it as a clean win.
- **Tennis.** The winner gets the sets, {{fact:forfeit-scores.tennisScore}}, but no games. A game ratio is never moved by a match nobody played.
- **Cricket.** Nothing is scored, so the match shows no score. Instead the side that did not turn up is charged its full overs at no runs, which pulls its net run rate down, while the winner's net run rate does not move. A Test has no fixed number of overs, so there the match is left out of net run rate altogether.
- **Chess.** A game lost by default is {{fact:forfeit-scores.boardgameScore}}, and it counts no colour, so it never changes who plays white next.
- **Any other sport.** The match is marked as a walkover, {{fact:forfeit-scores.genericScore}}, and no score is counted for either side.

## A retirement is different

A walkover means nothing was played. When a side stops during a match, that is a retirement, and a real score already exists. In football, hockey, ice hockey and any other sport, the real score stands when it is worse for the side that retired than the walkover score. A team that was already losing heavily cannot shrink the defeat by walking off.
