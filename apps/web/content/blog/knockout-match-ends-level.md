In a league a level match is a fair result: both sides take a share of the points and the table moves on. A knockout match has to send one side through, so a level score has to be broken. Each sport breaks it its own way, with a decider that grows out of how the sport is played. Set sports never need one, because a match cannot finish level.

## Why each sport breaks a tie differently

A good decider stays close to the sport. It keeps playing the same game for a short time, and if that still settles nothing, it narrows the game down to one skill that is quick to decide.

- **Football** plays two short extra halves, then goes to penalties. A new knockout stage plays halves of {{fact:knockout-match-ends-level.footballExtraTimeHalf}} minutes and {{fact:knockout-match-ends-level.footballKicks}} kicks each. Youth and mini-soccer take {{fact:knockout-match-ends-level.footballYouthKicks}} kicks each, because a shorter game for younger players gets a shorter shoot-out too.
- **Ice hockey** plays sudden-death overtime, so the first goal ends it, then a shoot-out. **Hockey** goes straight to a shoot-out.
- **Cricket** in the limited-overs formats plays a super over: one more over each, the whole match in miniature.
- **Chess** plays faster games: rapid, then blitz, then Armageddon. In Armageddon a draw counts as a win for Black, so it always ends with a winner.
- **Carrom** plays an extra board.
- **Volleyball, badminton, table tennis and tennis** need no decider. A match is won by winning more sets, games or points, and there is always a last one to win.

## When a decider can still leave it level

Some deciders can end level too. Extra time can finish level, which is why penalties follow it. Overtime can finish without a goal, which is why a shoot-out follows it. When every decider is used up and the match is still level, it cannot be settled by the rules any more, so it waits for you to decide who goes through. In the table, that is the last column.

A Test match has no decider at all: a drawn Test in a knockout waits for the organiser. A generic division has none either. Its results are entered by hand, so a knockout result has to name a winner when you enter it.

## Why a knockout has deciders and a league does not

The same sport can treat a level match two ways, because the two stages ask different questions. A league asks "how many points did each side earn?", and a draw answers it. A knockout asks "who goes through?", and a draw does not. So a new knockout stage starts with its sport's deciders on, while a new league stage starts with none and a level match stays a draw.

## Where to find it in Seazn

The deciders are part of the stage's **Match rules**, and a new knockout stage starts with its sport's deciders already on. You can change them, or switch them off, for the stage. A match whose deciders are all used up, or switched off, waits on the fixture list until you settle it. The match page shows spectators which deciders the stage plays.
