Two things on **Match Day** hand a match to someone who is not at your desk. A scoring link gives one phone one match. A **Match Day code** gives the Seazn Club Mobile App the day's matches for the competition, venue or courts you choose.

## A scoring link for one match

On a playing or called court, **Remote scoring** gives a QR code and a link for that match. Scan it on any phone and that phone scores the match, with no account. See [device links](/help/scoring/device-links).

1. Select the court.
2. Under **Remote scoring**, select **Create scoring link**.
3. Show the QR code to the scorer, or send the link.

**Open pad** opens the match's own page instead. A playing court shows **No scorer** while nobody has started scoring it, no official is assigned to it and it has no scoring link. The mark clears once a link exists.

## A Match Day code

A Match Day code is one QR code for the Seazn Club Mobile App. Scan it in the app and the app lists the day's matches and opens their scoring. Owners and admins make codes. A Viewer does not see the **Match Day code** button.

![The Match Day code sheet with the Covers choices, the Day, the two ticks and the Make code button, above a list of three active codes.](/help/scheduling/match-day-code.webp "The Match Day code sheet and its list of active codes.")

1. On Match Day, select **Match Day code**.
2. Under **Covers**, choose **Whole competition**, **One venue** or **Some courts**. For a venue, pick it from the list. For courts, tick each one. **Make code** stays off until you have ticked a court.
3. Pick the **Day**. It starts on today.
4. Tick what the code may do. Both are off until you tick them: **Approve pairings and brackets** and **Call matches to courts**.
5. Select **Make code**. The QR code appears.

The code works from 00:00 to 24:00 on its day, in your organisation's time zone, and lists the matches scheduled that day. A code for a later day waits until then. The list reads **Opens** and the date.

### What a code can do

- **Always:** list what it covers for the day, and open scoring for matches still to play or in play. A finished or cancelled match gets no scoring link.
- **Approve pairings and brackets:** review and approve the next Swiss round, or a knockout draw, in what it covers. A tie or a slot to change is still yours, on the web.
- **Call matches to courts:** call a match it covers onto a court it covers, and undo that call. The same rules apply as on Match Day, so a match whose player is on another court can't be called.

A code only reaches what it covers. A match or court outside what it covers is refused.

If you open a Match Day code in a browser, it shows **Open this with the Seazn Club Mobile App**.

### See and withdraw codes

Under **Active codes**, each code reads what it covers, its day and what it may do, for example **Court 2, Court 3 · Today**. **Show QR** brings its QR code back. **Withdraw** stops it at once and takes it off the list. The scoring links the code already opened keep working.

> **Example**
> You make four codes. The first covers the **Whole competition** today and has **Call matches to courts** ticked. The second covers **Hall A** today and has **Approve pairings and brackets** ticked. The third covers **Court 2** and **Court 3** today and has no ticks. The fourth covers the **Whole competition** tomorrow. You withdraw the first. The list now reads **Hall A · Today · Approves pairings and brackets**, **Court 2, Court 3 · Today** and **Whole competition · Opens Fri 20 Nov**. Each row has **Show QR** and **Withdraw**.
