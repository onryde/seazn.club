You score volleyball by tapping the half of the side that won the rally. The halves read **Home** and **Away**. The strip below them follows the set, the server and, indoors, the rotation.

## Choose the format

You pick a format when you create the division. A new volleyball division starts on **Beach**. A set is won by two clear points and has no cap.

| Format | Match | A set is played to | Deciding set | Substitutions |
|---|---|---|---|---|
| **Beach** | Best of 3 | 21 | 15 | None |
| **Indoor** | Best of 5 | 25 | 15 | Yes |

## Score a rally

1. Open the match in the console and start it.
2. Tap the half of the side that won the rally. The half reads **Tap to award the rally**.
3. Keep tapping. When a set is won, the next set opens.

The line above the scores says which set you are in, for example "Best of 5 · Set 2". It adds **Deuce** when both sides are one point short of the set's target and level: 24–24 indoor, 20–20 in a Beach set to 21.

> **Example**
> A Beach set is 20–20 and the pad shows **Deuce**. The home side wins two rallies in a row and the set closes 22–20. At 21–20 it is not over yet.

In Beach, and in Indoor when the side has a team sheet, the pad holds each rally and asks **Which player won it?** with the side's players. The rally counts whether you answer or not. **Send now** skips the countdown. See [crediting the player](/help/scoring/attribution). To undo a rally, press **Take back** on the ribbon.

## Serving and rotation

The strip shows **Sets**, **Serving** and, in Indoor only, **Rotation**. The side that wins a rally serves the next one.

In Indoor, the first tap at 0–0 of a set opens **Who served?** with **Home** and **Away**, before it records the rally. After you answer, the strip shows, for example, **Serving Home** and **Rotation 1**. If Away wins the serve, it reads **Serving Away** and **Rotation 2**.

In Beach the first tap is not interrupted, and **Serving Home** appears after it. The **Note the server** tile is there on both formats.

## Time-outs, sanctions and injuries

- **Time-out**: one tile per side.
- **Sanction**: one tile per side. The ladder is **Warning**, **Penalty**, **Expulsion**, **Disqualification**.
- **Injured, no sub**: one tile per side. It asks **Who is injured and can't be replaced?**

## The libero

The **Libero** tile appears for a side when its team sheet names a libero. It opens **Who comes off?** with the six players on court, each with a position badge such as S, OH, MB or OPP. See [lineups](/help/scoring/lineups) for building the sheet.

An ordinary substitution is under **More**, then **Substitution**. Beach has neither the Libero tile nor substitutions.

## Record a set's final score

**Set score** records a finished set as two numbers instead of rally by rally. Use it while the current set has no rally in it.

## Recording level

A new volleyball match opens at **Every detail**. See [choosing a detail level](/help/scoring/fidelity).

## The league table

Indoor pays 3 points for a win by 3–0 or 3–1, and 2 for a win by 3–2, with 1 for the 3–2 loser. Beach pays 2 for a win and 0 for a loss. The division's **Standings** tab lists the tie-break order under "Tie-break cascade": wins, points, set ratio, point ratio, head-to-head, then a drawing of lots.
