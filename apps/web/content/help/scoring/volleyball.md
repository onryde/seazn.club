Volleyball divisions score rally by rally: tap the half of the side that won the rally and the point is recorded. Two formats — **Indoor** (best of five, sets to 25, deciding set to 15, six on court with a bench) and **Beach** (pairs, best of three, sets to 21, deciding set to 15, and no substitutions at all). Neither format sets a ceiling on a set, so win-by-two can carry a set to 26-24 or 30-28.

## The board is the button

The two halves carry **Home** and **Away** rather than a roster — six names don't fit on a tile anyone can read across a hall, and the half is also the tap target. Each shows its points in the current set. Tap the winner's half — *Tap to award the rally* — and that's the entry.

The line above reads *Best of 5 · Set 2*, and adds **Deuce** once both sides are one point short of the set's own target — at 24-all indoors, at 20-all in a 21-point beach set, from the same rule rather than a hard-coded number.

## Serving and rotation

Everything positional lives on the strip below the scores: **Sets** (the match score in sets), **Serving**, and — indoor only — **Rotation**, the serving side's own court position, 1 to 6.

The side serving is never guessed. Volleyball is side-out, so the side that won the last rally serves the next, and from the first rally on the record answers by itself. For a beach **pair**, the declared service order names the actual player; an indoor six can't be resolved to a person, so only the side is shown. A libero is never named as the server, because a libero may not serve.

The rotation number needs one extra fact: who opened the set. Under side-out, the moment a point is scored that fact is gone — the next server is simply whoever won the last rally. So at 0-0 of a set, on an indoor fixture that fields a full six, the very first tap asks **Who served?** before recording the rally you tapped. One question, once per set, on the one tap where the answer still exists. **Note the server** is the same declaration as its own tile, offered at the same moment.

Beach is left alone: a pair has no six-position rotation to number, so nothing interrupts a two-tap sport.

## Who won the point

Volleyball's smallest side is a pair, so there's always someone to choose: after the tap the entry is held and asks **Which player won it?** with the side's on-court players. Answer it or let it go — the rally counts either way, and the panel offers **Send now** if you don't want to wait out the countdown. See [crediting the player](/help/scoring/attribution).

## Time-outs and sanctions

**Time-out** is a tile per side, one tap, no questions. **Sanction** is a tile per side too, offering the full ladder in order — **Warning**, **Penalty**, **Expulsion**, **Disqualification** — then who, when the side has more than one player on court.

## The libero

**Libero** appears as its own tile per side once either team sheet names a libero. It's a real lineup change, not a scoresheet tally: pick who comes off, then who comes on, and every row is badged with its court position so you're scanning for a position rather than reading six similar names. The libero herself carries a **Libero** tag.

Two rules are enforced for you rather than explained after the fact. A player coming on takes the position of the player going off — which is what keeps the player a libero replaced from being stranded off court. And an ordinary bench player can only come on as the return leg of a libero exchange, so if no libero is on court to come off, those candidates are shown with the reason beside the name instead of being silently dropped.

A libero replacement doesn't count against the ordinary substitution allowance, and there's no limit on them. Ordinary substitutions — the scoresheet's in/out box tally — live under **More**, which is a different fact from the libero exchange and doesn't stand in for it.

## A set's score, without the rallies

**Set score** records a finished set's points directly: two numbers, prefilled from where the current set stands. It's offered only while the current set has no rally in it, so it returns as each new set opens.

## Standings

Indoor pays the usual volleyball match points — 3-0 for a 3-0 or 3-1, and 2-1 for a 3-2. Beach pays a flat 2-0. Ties break on points, then matches won, then set ratio, then point ratio, then head-to-head.

## Recording level

Rally-by-rally is the finest level and needs a plan that includes it. Below that the halves stop being tappable and the pad says why. A note names the plan that unlocks it and adds *"Record each set's final score instead."*; the rally tile itself is greyed out, reading **Rally by rally is locked** and captioned *"Record each set's final score"*. Set score works at every level; time-outs, sanctions and the libero exchange from **Card** upwards. See [choosing a detail level](/help/scoring/fidelity).

## Common questions

**Why can't I substitute on a beach fixture?** A pair has no bench, so the beach format records no substitutions — and the pad doesn't offer an action the record would refuse.

**The rotation number disappeared.** It needs the set's opener, which is only capturable before the first point of a set. It comes back at 0-0 of the next set, which re-asks.

**Nobody's shown as serving.** That's deliberate rather than a gap: where the app can't establish the serve, it shows nothing rather than a placeholder that looks authoritative.
